Hamilton · parcel zoning

Which zone is every Hamilton parcel in?

Output produced, not yet interpreted

The City of Hamilton's parcel map was laid over its zoning map to record the zone in force on each property parcel. The result is a city-wide table, a web map and the counts below.

What this is, and is not

A map-overlay result from the City's public layers as downloaded on . The source calls it "a research dataset, not a zoning confirmation: the City's legal by-law text governs." It is a single snapshot with no history, and it has not yet been used to answer any question about housing or policy. The counts are of parcel records, not land area.

Was the match done right?

A validation script took a random sample of parcels, asked the City's own live zoning service which zone sits under a point inside each one, and compared the answer with the overlay.

    Source wording: "This confirms the projection and join are right. It does not check the City's layer against the legal by-law."

    How to read this: caveats

    • The OLT/OMB tag is not a live-appeal flag. Each common tag lines up with the city-wide by-law that introduced that zone family. It says the parent by-law was appealed, not that the parcel is under appeal today.
    • Current snapshot only. The City's server holds no history of the zoning layer. Nine zoning polygons carry impossible dates (up to 2105).
    • Former by-laws still govern 27% of parcels, and their codes are not comparable with 05-200 codes.
    • Shared and doubtful shapes. Condo units share footprints; 12 rolls share one 19.5 km² polygon covering the harbour; 495 rows are flagged as suspect geometry.
    • Exceptions and holdings change what is permitted. The data shows that one applies, not what it says.
    • Licence. The layers are published under the City's Open Data Licence according to McMaster Library's catalogue record; the City's own open-data page could not be opened to confirm it.

    The interactive map

    The branch also holds a static web map of every parcel (hamilton/parcel_zoning/site/). It is not copied into this site because its data files are large. To view it, check out branch claude/nice-davinci-kpvdwk and serve that folder, as its README describes:

    cd hamilton/parcel_zoning/site && python3 -m http.server 8000

    Opening its index.html directly from disk will not load the data, according to the README.
