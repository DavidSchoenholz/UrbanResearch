# UrbanResearch
Interesting things that happen to include things in the city sphere of life

## Start here

A plain-language overview of the work so far is in [`docs/`](docs/index.html): open `docs/index.html` in a browser (it works straight from disk), or publish it with GitHub Pages (Settings → Pages → Deploy from a branch → this branch, folder `/docs`).

The work itself lives on three unmerged branches:

- **Toronto feasibility study** ([`claude/determined-lovelace-oc32xm`](https://github.com/DavidSchoenholz/UrbanResearch/tree/claude/determined-lovelace-oc32xm)): can Toronto's open data support a study of how zoning relates to housing completions? Verdict "GO WITH LIMITS".
- **Phase 2 analysis pipeline** ([`claude/optimistic-fermat-c1mogk`](https://github.com/DavidSchoenholz/UrbanResearch/tree/claude/optimistic-fermat-c1mogk)): code for following projects from zoning to application, permit and completion, tested on synthetic data only. Also holds the "Ideas to try next" list.
- **Hamilton parcel zoning** ([`claude/nice-davinci-kpvdwk`](https://github.com/DavidSchoenholz/UrbanResearch/tree/claude/nice-davinci-kpvdwk)): the zone on each of Hamilton's 177,753 parcel polygons, matched from the City's public maps; not yet interpreted.
